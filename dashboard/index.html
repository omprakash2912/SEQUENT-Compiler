Binary Format Specification (.seqc)

SEQUENT implements a 16-byte fixed binary container header [SEQC(4) | ver(2) | flags(2) | payload_len(4) | crc32(4)]. The Virtual Machine verifies payload length and IEEE 802.3 CRC32 before executing, preventing execution of corrupted or tampered bytecode.
